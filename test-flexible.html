Dynamic Category Test

This system now automatically reads categories from your Google Sheet data!

🎉 Benefits of the New Flexible System:

  • Any Categories: Works with Restaurants, Cafes, Retail, Services - anything!
  • Auto-Detection: Reads categories directly from your Google Sheet
  • No Code Changes: Just update your Google Sheet and it adapts
  • Shortcode Control: Still supports limiting categories via shortcode
  • Backwards Compatible: Your existing data still works perfectly

Example Usage:

[biz_location_finder] - Shows all categories found in data
[biz_location_finder categories="restaurants,cafes"] - Shows only specified categories
[biz_location_finder search="false"] - Hides search functionality
[biz_location_finder counters="false"] - Hides counter badges
